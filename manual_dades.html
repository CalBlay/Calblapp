Manual d’usuari de Dades

Manteniment i Cuina central · Guia pas a pas per a l’usuari final

Aquest manual explica com consultar i mantenir les dades mestres compartides dels mòduls Manteniment i Cuina central. Les dues rutes mostren la mateixa pantalla i treballen amb els mateixos registres.

Important: qualsevol canvi desat des d’un dels dos mòduls apareix també a l’altre. Revisa sempre les dades abans de desar o eliminar.

1. Com entrar a Dades

Des del menú principal, entra a Manteniment → Dades o a Cuina central → Dades. Les dues opcions obren la mateixa pantalla i treballen amb els mateixos registres.

Si no veus l’opció Dades: contacta amb la persona administradora de l’aplicació. L’usuari final no ha de configurar permisos.

Consultar una màquina

  1. Obre Maquinària.
  2. Cerca per codi, nom, centre, ubicació, zona, marca, model o proveïdor.
  3. Clica una targeta per desplegar-la.
  4. Revisa els tiquets, l’estat obert, les hores reals i l’última actuació.
  5. Clica Fitxa completa per consultar Resum, Tickets, Cronologia i Dades.

Crear una màquina

  1. Clica +.
  2. Informa el codi i el nom. Com a mínim un dels dos ha d’identificar la màquina.
  3. Selecciona el centre i una ubicació vàlida.
  4. Selecciona una zona si la ubicació en té.
  5. Completa marca, model, número de sèrie i proveïdor, si escau.
  6. Deixa marcada l’opció Activa si està en servei.
  7. Clica Crear màquina.

Per editar, desplega la targeta, modifica els camps i clica Guardar canvis. Si ja no s’utilitza, és preferible desmarcar Activa per conservar l’historial.

Consultar plantilles

  1. Obre Preventius.
  2. Utilitza el cercador i els filtres de temporalitat, centre, ubicació i zona.
  3. Selecciona una plantilla per veure periodicitat, última revisió, observacions, operaris, seccions i tasques.
  4. Clica el nom per obrir la fitxa completa o Historial per veure les revisions.

Crear una plantilla

  1. Clica + i escriu un nom clar.
  2. Selecciona la periodicitat.
  3. Assigna centre, ubicació, zona i operaris.
  4. Afegeix les seccions i les tasques de comprovació.
  5. Revisa l’estat actiu i desa.

Importar plantilles

  1. Clica Seleccionar fitxer i tria un Excel o CSV.
  2. Revisa la previsualització, el model detectat i els avisos.
  3. En el model B, tria plantilla fusionada, una per temporalitat o temporalitats concretes.
  4. Clica Importar només quan la previsualització sigui correcta.

Les plantilles es poden editar, exportar a PDF o Excel i eliminar. No eliminis una plantilla si encara cal conservar-ne l’ús operatiu o l’historial.

Crear un proveïdor

  1. Obre Proveïdors i clica +.
  2. Escriu el nom, que és obligatori.
  3. Completa correu electrònic, telèfon, especialitat i notes.
  4. Mantén Actiu marcat si es pot seleccionar en noves fitxes.
  5. Clica Crear proveïdor.

Per editar, selecciona el proveïdor, modifica les dades i clica Guardar canvis. Si ja no s’utilitza, desactiva’l per conservar les referències existents.

La jerarquia és Centre → Ubicació → Zona. Cal definir-la abans de crear màquines o plantilles preventives.

Crear un centre

  1. Obre Centres i clica Nou centre.
  2. Informa el nom i el codi.
  3. Selecciona Propi o Extern.
  4. Indica les hores i els minuts de desplaçament.
  5. Clica Crear centre.

Afegir ubicacions i zones

  1. Obre la targeta del centre.
  2. Clica Afegir ubicació i escriu-ne el nom.
  3. Selecciona la ubicació i clica Afegir zona per cada zona.
  4. Evita noms duplicats i clica Desar.

Abans d’eliminar un centre, ubicació o zona, comprova que no estigui utilitzat per màquines o preventius.

9. Bones pràctiques

  • Utilitza codis únics i noms consistents.
  • Cerca abans d’afegir per evitar duplicats.
  • No canviïs la ubicació d’una màquina sense verificar-la físicament.
  • Prefereix desactivar abans que eliminar.
  • Revisa la previsualització abans d’importar preventius.
  • Després de desar, comprova el registre a la llista.
